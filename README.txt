MONTHSARY WEBSITE — Lancer & Bear

1. Open index.html to preview the website.
2. Replace photos/photo1.svg ... photo6.svg with your own photos.
   Easiest method: edit index.html and change .svg to .jpg/.png after putting your images in the photos folder.
3. For music, place your legally obtained copy of the song as music.mp3 in this folder.
4. To put it online for a QR code, upload this folder to a static host such as GitHub Pages or another host.
5. After you have the final public URL, generate a QR code from that URL. The included QR code is only a placeholder.
